隐私政策

生效日期：2026 年 10 月 27 日

DevDisk（以下简称“本应用”）由朱文斌开发，是一款 macOS 本机磁盘分析与清理工具。本政策说明本应用处理哪些信息、何时连接第三方服务，以及你如何联系开发者。

1. 本机处理的信息

磁盘扫描、目录大小计算、已安装应用识别、网络接口速率统计和进程流量统计均在你的 Mac 上进行。扫描可能读取你选择或应用预设的本机目录，并处理路径、文件大小、修改时间、应用名称及扫描结果。本应用将设置、扫描摘要和清理记录保存在本机，不会把扫描到的文件、文件名、路径、应用清单或扫描结果上传给开发者。

网络速率和进程流量数据由 macOS 本机接口及系统工具计算，仅用于在应用界面展示，不会发送给开发者或用于广告追踪。

2. 公网 IP 查询及第三方服务

当你打开网络详情面板时，本应用会请求 ipwho.is 查询公网 IP 和国家/地区信息。如果该服务请求失败，本应用会向 ipify 请求公网 IP。该请求会使对应服务看到你的公网 IP 地址及常规网络请求信息；ipwho.is 可能返回国家/地区代码。此功能不会发送本机扫描结果、文件内容或进程流量明细。

上述服务由第三方独立运营，其服务器日志、保留期限和隐私实践受各自政策约束。请查阅 ipwho.is 网站和 ipify 网站的最新说明。本应用不控制第三方服务如何处理其收到的请求。

3. 文件访问与清理

本应用需要读取本机目录的元数据以计算占用。macOS 的隐私权限可能限制部分目录的访问；无法读取的项目不会被当作空目录处理。清理操作由你在应用中选择并确认。不同项目可能被移入废纸篓；对应用明确提示为永久删除的项目，确认后将无法通过废纸篓恢复。

4. 广告、分析与账户

本应用不要求创建账户，不包含广告或分析 SDK，也不使用扫描数据进行画像或广告定向。

5. 数据保留与控制

本机设置、扫描摘要和清理记录保存在你的 Mac 上，由你控制设备和本地应用数据。本应用不会在开发者服务器上保存这些信息。macOS 删除应用时不一定会自动移除其本机偏好设置或容器数据；如需彻底清除，请在移除应用前通过 macOS 管理对应的本机应用数据。

6. 未成年人

本应用面向 macOS 开发者，不会有意收集未成年人的个人信息。

7. 政策更新

当应用的数据处理方式发生变化时，开发者会更新本页面的生效日期和内容。请通过本页面查看当前版本。

8. 联系开发者

如对本政策或隐私问题有疑问，可通过 GitHub Issues 联系开发者。请勿在公开 Issue 中提交密码、密钥、个人文件路径或其他敏感信息。

本页面为 DevDisk 项目的隐私说明。第三方服务的处理行为以其自身公布的政策为准。
